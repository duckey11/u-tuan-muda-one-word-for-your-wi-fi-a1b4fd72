# u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72

One Word for Your Wi-Fi — a make.fun entry. The program writes a single
word describing the entrant's home Wi-Fi to `/output/entry.txt`.

The word is **liar**: the Wi-Fi icon shows full bars while nothing loads.
The network is not slow, it is lying to your face.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`.
